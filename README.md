# Свадебное приглашение

Next.js + Tailwind CSS лендинг-приглашение для Александра и Юлии.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Сборка

```bash
npm run build
npm run start
```

## Что заменить перед публикацией

- В [app/page.tsx](app/page.tsx) можно заменить плейсхолдеры детских фото и финальной фотографии на реальные изображения.
- В блоке локации замените текст `Адрес будет добавлен` на точный адрес.
- Для Telegram-чата замените декоративный QR-блок на реальный QR-код или ссылку.
